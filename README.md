# Yolov8-XiaomiSU7-vs-Porsche-Detection
A computer vision course project based on YOLOv8 to distinguish between Xiaomi SU7 and Porsche vehicles.

# Final Project: Xiaomi SU7 vs. Porsche Detection

## Project Introduction
This is a Computer Vision course final project based on **YOLOv8**. The goal is to solve the fine-grained visual classification problem between **Xiaomi SU7** and **Porsche** vehicles, which share high visual similarities. We constructed a dataset, processed labels from VOC to YOLO format, and trained a YOLOv8s model to achieve high detection accuracy.

This repository contains the source code, the trained model weights, and the necessary scripts for inference.

---

## Requirements: Software
To run this project, you need a Python environment (Python 3.8+) with the necessary dependencies installed.
